# Heft Rollup Plugin Example

This example demonstrates how to use the heft-rollup-plugin.

## Setup

1. Install dependencies: `npm install`
2. Build the project: `npm run build`

This will:
1. Compile TypeScript files to the `lib/` directory
2. Run Rollup to bundle the compiled JavaScript to `dist/bundle.js`

## Configuration

- `config/heft.json`: Configures Heft to use the rollup plugin
- `rollup.config.js`: Rollup configuration for bundling
- `tsconfig.json`: TypeScript configuration
